# Project Memory

## Project Summary

This project is an intelligent data analysis platform with:
- data collection
- anti-crawl aware scraping
- analytics and EDA
- ML and DL workflows
- data visualization
- enterprise-style full-stack architecture

## Current Architecture Snapshot

Backend:
- FastAPI
- SQLAlchemy
- PostgreSQL
- Redis
- Celery

Frontend:
- React 18
- TypeScript
- Vite
- Tailwind
- charting and dashboard libraries

Data and AI:
- pandas / numpy / scipy
- scikit-learn
- xgboost / lightgbm
- torch / transformers
- scrapy / playwright / beautifulsoup4

## Default Working Assumptions

- Prefer modular backend design with typed schemas and clear task boundaries.
- Prefer reproducible analysis and model workflows.
- Prefer compliant scraping with explicit anti-crawl handling.
- Prefer dashboards that are practical and readable, not just visually dense.
