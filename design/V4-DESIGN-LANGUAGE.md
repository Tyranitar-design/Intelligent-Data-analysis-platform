## 标志组件规范（实现约定）

1. **圆环仪表盘**（置信度）：SVG 弧 ~270°，轨道 `surface-3`，进度亮青（可渐变），
   中心大数字用 `.num` + 下方 0/100 刻度注释。**数据必须真实**（confidence × 100）。
2. **字段覆盖矩阵**：行=字段、列=样本窗（8-12 格）；4 档色阶——≥80% 亮青实、
   50-80% 亮青 60%、20-50% 青灰、<20% 暗灰；悬浮显示字段与覆盖率。
3. **强度三格条**：3 个 6×12px 圆角小格，强=3 格亮青 / 中=2 / 弱=1。
4. **delta chip**：`+12.6%` ↑ 绿字淡青底 / `-x%` 红字淡红底。
5. **KPI 大数字**：`text-3xl+` + `.num`，主色或前景色；副行（较上期 / 近 7 日）。
6. **任务进度条**：`h-1.5` 轨道 + 亮青填充 + 右侧百分比 `.num`。
7. **管道节点**：等待中=灰实心 / 进行中=亮青实心 + ring 光晕环 / 完成=亮青带勾 /
   数字计数在节点下方。连接线用 hairline。
8. **实时活动流**：状态点（绿✓ / 红✗ / 亮青→）+ mono 时间 + 文本 + 右端引用 ID。
