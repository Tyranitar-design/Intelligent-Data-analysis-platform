## 三、反爬能力评估

### ✅ 已具备的反爬能力

| 能力 | 实现 | 级别 |
|------|------|------|
| **User-Agent 轮换** | fake_useragent + 随机选择 | ⭐⭐⭐ |
| **请求限速** | 可配置延迟，默认 1s | ⭐⭐⭐⭐ |
| **自动重试 + 指数退避** | 403/429 自动退避重试 | ⭐⭐⭐⭐ |
| **Scrapling Fetcher** | Cloudflare 反爬绕过 | ⭐⭐⭐ |
| **robots.txt 合规** | 自动检查 + Crawl-delay 遵守 | ⭐⭐⭐⭐ |
| **代理 IP 支持** | httpx proxy 参数 | ⭐⭐ |
| **请求头增强** | 反爬增强器生成完整浏览器头 | ⭐⭐⭐ |
| **自动回退** | httpx 失败 → Scrapling | ⭐⭐⭐ |

### ⚠️ 当前限制

| 限制 | 说明 | 解决方案 |
|------|------|----------|
| **StealthyFetcher** | 需要安装 patchright/camoufox，当前未安装 | 按需安装：`pip install patchright` |
| **代理池** | 当前无自动代理池 | 可接入付费代理 API |
| **验证码处理** | 不支持自动解验证码 | 合规采集 + API 优先 |
| **JavaScript 重度页面** | Scrapling Fetcher 可处理，StealthyFetcher 更强 | 安装 patchright 后升级 |

### 🛡️ 反爬策略架构

```
用户请求
    ↓
robots.txt 合规检查 ← 自动检查
    ↓
httpx (轻量) ← 请求头增强 + UA轮换 + 限速
    ↓ 失败?
Scrapling Fetcher ← Cloudflare绕过 + 动态渲染
    ↓ 仍失败?
Scrapling StealthyFetcher ← 完整浏览器模拟 (需patchright)
    ↓
自动重试 (指数退避) + 代理回退
```
