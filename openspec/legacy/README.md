# OpenSpec Legacy Archive

This folder preserves historical OpenSpec-style documents that are still useful as references but do not match the current active delta format.

## Rules

- Do not treat files in this folder as active changes.
- Do not extend legacy change folders for new work.
- Create new work with `openspec new change <name>`.
- If a legacy document is still valuable, migrate its content into a new active change instead of editing it in place.

## Migration Rationale

These files were moved here to restore a clean active OpenSpec baseline and allow `openspec validate --all` to focus on current-format changes.
