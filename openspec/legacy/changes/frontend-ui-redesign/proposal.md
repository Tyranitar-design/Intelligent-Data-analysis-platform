## 3. 设计方向

### 3.1 风格定位

**主色调**: 深邃科技蓝 + 活力橙点缀

| 元素 | 选择 | 说明 |
|------|------|------|
| **主色** | #0F172A (深蓝黑) | 专业、深沉 |
| **次色** | #1E293B ( slate-800 ) | 卡片背景 |
| **强调色** | #F59E0B (琥珀金) | 重要操作、高亮 |
| **辅助色** | #3B82F6 (科技蓝) | 信息、数据 |
| **成功色** | #10B981 (翠绿) | 成功状态 |
| **警告色** | #EF4444 (警示红) | 警告、错误 |

### 3.2 字体系统

| 用途 | 字体 | 大小 |
|------|------|------|
| 标题 | "Noto Sans SC", sans-serif | 24-32px |
| 正文 | "Noto Sans SC", sans-serif | 14-16px |
| 数据 | "JetBrains Mono", monospace | 12-14px |
| 按钮 | "Noto Sans SC", sans-serif | 14px |

### 3.3 设计风格

**方向**: 现代科技企业风格 (Modern Tech Enterprise)

特征：
- 深色主题为主，凸显数据可视化
- 玻璃拟态 (Glassmorphism) 卡片效果
- 微妙的渐变和光晕
- 流畅的页面过渡动画
- 数据可视化优先的布局

### 3.4 动画系统

| 场景 | 动画类型 | 时长 |
|------|----------|------|
| 页面进入 | 淡入 + 上移 | 300ms |
| 卡片悬停 | 轻微上浮 + 阴影加深 | 200ms |
| 按钮点击 | 缩放反馈 | 100ms |
| 数据加载 | 骨架屏 shimmer | 持续 |
| 页面切换 | 淡入淡出 | 250ms |
